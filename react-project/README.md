# ✨ Random Quote Generator

A simple and interactive Random Quote Generator built with React.js.

This project generates random motivational quotes whenever a user clicks the "New Quote" button. It helps users stay motivated and positive.

## 🚀 Features

* Displays motivational quotes.
* Generates a new random quote on button click.
* Simple and user-friendly interface.
* Uses React useState Hook.

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS


## ⚙️ Installation

Clone the repository:

bash
git clone YOUR_GITHUB_REPOSITORY_LINK


Go to the project folder:

bash
cd random-quote-app


Install dependencies:

bash
npm install


Run the project:

bash
npm run dev
